# Solarity

Friends who see each other's progress toward their goals motivate each other to keep going.

## Stack

Next.js (App Router) · TypeScript · Tailwind · Supabase · Upstash Redis · Vercel

## Getting started

```bash
npm install
npm run dev
```

The app talks to the hosted Supabase project via `.env.local` — no local Postgres needed. See [`docs/testing.md`](docs/testing.md).
